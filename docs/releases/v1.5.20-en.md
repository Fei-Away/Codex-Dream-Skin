# Codex Dream Skin v1.5.20

[中文](https://github.com/Fei-Away/Codex-Dream-Skin/blob/v1.5.20/docs/releases/v1.5.20.md) · **English**

This update fixes home tagline styling, makes Windows respect an existing custom Codex configuration directory, and fixes macOS session identification across different language environments.

## Fixes and improvements

- **Home tagline styling (macOS / Windows)**: A valid `font-size` (12–20px) set by theme authors on the public `[data-ds-part="home-hero"]` part in `theme.css` now applies to the tagline. Its color follows that part, retaining 76% opacity. Without a specified size, the defaults remain 13px on desktop and 11px in narrow windows. Addresses [#427](https://github.com/Fei-Away/Codex-Dream-Skin/issues/427).
- **Windows custom configuration directory**: Installation, startup and restore now follow an existing `CODEX_HOME`, using the default `.codex` directory when the variable is unset or empty. Backups record their source directory and cannot be restored into a different home. Invalid paths produce an explicit error. Addresses [#428](https://github.com/Fei-Away/Codex-Dream-Skin/issues/428).
- **macOS session identification**: Process start times are now read with `LC_ALL=C`, preventing differences in localized date text from blocking identification of an existing session. Process identity checks remain in place. Addresses [#429](https://github.com/Fei-Away/Codex-Dream-Skin/issues/429).

## Upgrading and usage

For a custom directory on Windows, the Dream Skin installer, tray and official Codex app must all receive the same existing `CODEX_HOME`. A variable set only in a terminal may not reach the official app when it is activated through Microsoft Store. Ensure the user environment setting is available to newly started apps; sign out of Windows and back in if needed. There is no need to create an empty directory for this upgrade. A fresh directory may require Codex sign-in or onboarding.

If a backup already exists, restore using the original home before switching `CODEX_HOME`. Dream Skin still backs up and adjusts appearance settings. Theme installation remains separate from API configuration and does not automatically rewrite API keys, base URLs or model provider settings.

On macOS, existing session records with non-English start times are not migrated automatically. If an old session still cannot be identified after upgrading, fully quit the old Codex and Dream Skin sessions and start them again. Restart macOS if needed; do not force-terminate a process based only on a PID in an old record.
