- macOS: fall back to the fixed official release URL when the GitHub API is rate limited, with bounded and unambiguous redirect parsing (#401).
- macOS: reduce watcher polling during a prolonged disconnect while retaining reconnection, and read the update version from the installed application bundle (#218, #387).
- Windows: reject horizontal overflow during renderer verification (#386), and use an isolated managed CDP profile (#390).

### Windows profile / Windows 登录说明

The managed profile is separate from the official Codex profile. First use requires signing in again; subsequent starts should retain that login. This does not guarantee compatibility with every upstream Store/runtime version. Issue #395 remains separate until its runtime-handoff behavior is verified.

受管 profile 与官方 Codex profile 隔离，首次需要重新登录，后续启动应保留登录。此变更不代表所有 Store/runtime 版本均已兼容；#395 仍需对应版本实机验证，不随本次版本准备自动关闭。
