# Codex Dream Skin v1.5.19

**中文** · [English](https://github.com/Fei-Away/Codex-Dream-Skin/blob/v1.5.19/docs/releases/v1.5.19-en.md)

本次更新带来**按主题调节背景透明度**和**删除已保存主题**，Windows 新增原生主题管理窗口，同时修复 Codex / ChatGPT 26.924–26.930 的多处显示与交互问题。

## 新增功能

- **背景透明度随主题保存**：macOS 和 Windows 都可以在 0–100% 之间调节：0% 不透明，100% 全透明，文字和图标不受影响。点击「跟随主题」恢复作者设定；作者未指定时使用默认 30%。
- **清理不再使用的本机主题**：确认后移到系统废纸篓或回收站，误删可从系统还原。正在使用的主题需先切换；原始 ZIP、恢复备份和社区发布记录保留。回应 [#422](https://github.com/Fei-Away/Codex-Dream-Skin/issues/422)。
- **Windows 原生主题管理窗口**：从桌面、开始菜单或双击托盘图标打开，集中调整透明度和删除主题。重复打开会恢复已有窗口，支持中文、英文及 DreamSkin 应用图标。

## 修复与改进

- **新版界面适配**：修复会话页面空白、壁纸被遮挡、标题栏与侧栏接缝，以及代码块和展开表格的配色问题；修复装饰层拦截原生鼠标操作的问题。
- **Windows 显示**：修复首页输入框裁切、顶栏重复底色和停靠侧栏圆角漏底。
- **渲染性能**：减少滚动及 ChatGPT Work / Codex 切换时的样式重算；减少 Windows「减少动态效果」模式下的过渡开销。
- **Windows 主题操作**：修复回收站操作异常；升级或卸载时正常关闭主题管理窗口，避免旧进程占用文件。

## 升级与使用

| 平台 | 新功能入口 |
| --- | --- |
| macOS | 菜单栏 → **主题**：调节背景透明度、跟随主题、删除已保存主题 |
| Windows | 桌面 / 开始菜单 → **Codex Dream Skin**，或双击托盘图标 |

Windows 的导入和切换主题仍在托盘菜单中；原 PowerShell 主题选择窗口已移除。透明度调整保存在本机，不会改写主题包。

操作与还原方法见[本机主题管理](https://github.com/Fei-Away/Codex-Dream-Skin/blob/v1.5.19/docs/theme-management.md)。
