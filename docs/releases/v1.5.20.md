# Codex Dream Skin v1.5.20

**中文** · [English](https://github.com/Fei-Away/Codex-Dream-Skin/blob/v1.5.20/docs/releases/v1.5.20-en.md)

本次更新修复首页副文案样式不跟随主题的问题，让 Windows 正确使用已有的自定义 Codex 配置目录，并修复 macOS 不同语言环境下的会话识别问题。

## 修复与改进

- **首页副文案样式（macOS / Windows）**：主题作者在 `theme.css` 中为公开部件 `[data-ds-part="home-hero"]` 设置的合法 `font-size`（12–20px）现在会应用到副文案；颜色跟随该部件，保留 76% 不透明度。未指定字号时，仍使用桌面 13px、窄窗口 11px 的默认值。对应 [#427](https://github.com/Fei-Away/Codex-Dream-Skin/issues/427)。
- **Windows 自定义配置目录**：安装、启动和恢复现在遵循已有的 `CODEX_HOME`，未设置或为空时使用默认 `.codex` 目录。备份会记录来源目录，拒绝把一个目录的配置备份恢复到另一个目录；无效路径会明确报错。对应 [#428](https://github.com/Fei-Away/Codex-Dream-Skin/issues/428)。
- **macOS 会话识别**：读取进程启动时间时统一使用 `LC_ALL=C`，避免中文等语言环境造成时间文本不一致、进而无法确认已有会话的问题。进程身份校验仍然保留。对应 [#429](https://github.com/Fei-Away/Codex-Dream-Skin/issues/429)。

## 升级与使用

Windows 使用自定义目录时，Dream Skin 安装器、托盘和官方 Codex 必须读取到同一个已有的 `CODEX_HOME`。仅在终端设置变量，可能无法传递给通过 Microsoft Store 激活的官方应用。请确认用户级环境设置已对新启动的应用生效，必要时注销 Windows 后重新登录。无需为升级创建空目录；新目录可能要求重新登录 Codex 或完成首次设置。

已有备份时，如需切换 `CODEX_HOME`，请先在原目录完成恢复，再使用新目录。Dream Skin 仍会备份并调整外观配置；换肤与 API 配置保持独立，不自动改写 API Key、Base URL 或模型供应商设置。

macOS 不会自动迁移旧会话记录中的非英文启动时间。如果升级后仍提示无法确认旧会话，请完整退出旧的 Codex 和 Dream Skin 会话后重新启动；必要时重启 macOS，不要仅凭旧记录中的 PID 强制结束进程。
