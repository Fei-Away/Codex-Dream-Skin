# Codex Dream Skin v1.5.19

[中文](https://github.com/Fei-Away/Codex-Dream-Skin/blob/v1.5.19/docs/releases/v1.5.19.md) · **English**

This release adds **per-theme background transparency** and **saved theme deletion**, introduces a native Windows theme manager, and fixes rendering and interaction issues in Codex / ChatGPT 26.924–26.930.

## New features

- **Per-theme background transparency.** Adjust transparency from 0% (opaque) to 100% (fully transparent) on macOS and Windows without fading text or icons. Choose **Follow theme** to restore the author's value, or the default 30% when no value is specified.
- **Remove saved local themes.** After confirmation, themes move to the system Trash or Recycle Bin, where they can be restored. Switch away from the active theme before deleting it. Source ZIPs, recovery backups and community publications are retained. Addresses [#422](https://github.com/Fei-Away/Codex-Dream-Skin/issues/422).
- **Native Windows theme manager.** Open it from the desktop, Start Menu or by double-clicking the tray icon to adjust transparency and delete themes. Opening it again restores the existing window. It supports Chinese and English and includes the DreamSkin app icon.

## Fixes and improvements

- **Updated interface compatibility:** Fix blank conversation pages, obscured wallpapers, title bar and sidebar seams, and colors in code blocks and expanded tables. Fix decorative layers intercepting native mouse interactions.
- **Windows rendering:** Fix clipped input areas on the home page, duplicate title bar backgrounds and exposed corners along the docked sidebar.
- **Rendering performance:** Reduce style recalculation while scrolling and switching between ChatGPT Work and Codex, and reduce transition overhead when reduced motion is enabled on Windows.
- **Windows theme operations:** Fix Recycle Bin errors. Close the theme manager gracefully during upgrades or uninstall so its existing process does not keep files in use.

## Upgrading and usage

| Platform | Where to find the new controls |
| --- | --- |
| macOS | Menu bar → **Theme**: background transparency, Follow theme and Delete saved theme |
| Windows | Desktop / Start Menu → **Codex Dream Skin**, or double-click the tray icon |

On Windows, importing and switching themes remain in the tray menu; the former PowerShell theme-selection window has been removed. Transparency preferences are saved locally and do not modify theme packages.

See [local theme management](https://github.com/Fei-Away/Codex-Dream-Skin/blob/v1.5.19/docs/theme-management.md#english) for controls and restoration instructions.
