# Codex Dream Skin v1.5.21

[中文](https://github.com/Fei-Away/Codex-Dream-Skin/blob/v1.5.21/docs/releases/v1.5.21.md) · **English**

This update fixes Windows installation, startup and theme operations failing on a harmless warning when Node.js environment proxy support is enabled. Addresses [#435](https://github.com/Fei-Away/Codex-Dream-Skin/issues/435).

## Fixes and improvements

- **Windows proxy compatibility**: With `NODE_USE_ENV_PROXY=1`, the Node.js `UNDICI-EHPA` experimental warning no longer causes Windows PowerShell 5.1 to treat an operation as failed. Image checks, theme imports and theme application still use actual validation results to determine success. Invalid images, CSS and theme packages remain rejected.
- **Windows startup decisions**: Structured helper results are read separately from warnings, so harmless warnings no longer interfere with hidden-window detection or decisions to preserve a skin already displayed. Diagnostics for actual failures are retained.
- **macOS**: No runtime behavior changes in this release; its version is aligned to 1.5.21.

## Upgrading and usage

Windows users can install the new package over their existing installation. This fix does not require disabling the proxy or suppressing all Node.js warnings. The installer does not rewrite your proxy environment variables.
